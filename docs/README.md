# Solar engineering documentation

This repository remains Solar. The current work extends the existing launcher,
services, and ROM tooling for an Innioasis Y1 private test build; it does not
rename the project or replace Solar's established architecture.

Current status: **private APK test candidate, not a public firmware release**.
The debug application and companion APKs build successfully, all host unit
tests pass, and repository lint passes with the inherited app findings frozen
in a baseline. Physical Y1 behavior, release signing, and a flashable ROM are
still gated as described in [Release readiness](RELEASE-READINESS.md).
